GitHub & Firebase Hosting 公開ガイド

1. GitHub リポジトリ (`lendapp`) の作成とアップロード

作成した `index.html` ファイルをGitHubにアップロードします。

git init
git add index.html
git commit -m "Initial commit for lendapp"
git branch -M main
git remote add origin https://github.com/あなたのユーザー名/lendapp.git
git push -u origin main

2. Firebase Hosting へのデプロイ手順

ターミナルから以下のコマンドを実行して公開URLを取得します。

# Firebase CLIのログインと初期化
npm install -g firebase-tools
firebase login
firebase init hosting
# (Public directoryは「.」またはそのまま「index.html」の配置場所を指定)
# デプロイ実行
firebase deploy --only hosting
